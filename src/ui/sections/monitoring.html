Fleet health
managed host(s) · checked in the background, kept on this machine for 7 days
vops checks your hosts over SSH on its own and keeps 7 days of readings on this machine — so this page has history the moment you open it, and older data is discarded automatically. Nothing is uploaded anywhere. To be alerted when you're away, set a watch (Availability → “Notify me”, or vops watch) — that path is separate and opt-in.
Background collection is switched off (VOPS_METRICS_DISABLED=1). The readings below are only what “Check now” gathers.
