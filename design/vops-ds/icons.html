Icon system

Fifteen icons for the control plane, drawn from what each thing actually is in vops rather than borrowed from a general-purpose set. Each is a monochrome skeleton plus a single accent shape — the same lit-face-over-dark-side reading as the vops mark.

Four of them share one form on purpose: a slab that means a machine, differing only in what sits inside it.

The rule

One accent shape per icon. Never two, never zero. It marks the part of the glyph that carries the meaning — the status LED on a server, the shorter bar in a price comparison, the prompt in a terminal — so colour follows sense rather than decorating the outline.

+ =
  • currentColor
    The skeleton. Inherits the row's text colour, so it dims with the label and brightens on hover exactly like type.
  • .a / .as
    The accent. Resolves through --icon-accent, defaulting to the theme accent — it stays saturated when the label is faint.

The slab family

A control plane is mostly one noun — a machine — seen four ways. Repeating the outer form and changing only the interior is what a borrowed set cannot do: it says these four screens are about the same object, and the interior says which question you are asking of it.

The set

Thirteen sidebar destinations plus hosts and catalog, which appear in detail views. 24×24 grid, 1.7 stroke, round caps and joins — the same construction as the Dymmi set, so the two products read as siblings without sharing a hue.

Size ladder

17px is the sidebar size and the one every glyph is hinted for. Below 16 the accent shape is the first thing to go muddy, which is why none of them rely on a detail smaller than roughly 3 grid units.

In place

The rail in both themes. The active row swaps --icon-accent to the lighter face tone so the duotone survives on an accent-tinted background instead of collapsing into one flat colour.

Implementation

One set, two themes
There is no dark file and no light file. The body is currentColor and the accent is a token, so both themes fall out of the variables already in tailwind.css.
Offline
Inline SVG in the bundle, same as today. No sprite sheet, no font, no network — the dashboard still opens with the machine unplugged.
Drop-in
Keys match the current ICONS object one-for-one. nav and navFooter keep referencing ICONS.x unchanged.

Wiring

Two rules in tailwind.css teach the existing markup to render the accent.

/* the accent stays saturated while the skeleton dims with the label */
.nav-item svg .a  { fill: var(--icon-accent, var(--accent)); stroke: none; }
.nav-item svg .as { stroke: var(--icon-accent, var(--accent)); }

/* on an accent-tinted row, shift the accent up so it does not merge */
.nav-item-active { --icon-accent: var(--face); }
