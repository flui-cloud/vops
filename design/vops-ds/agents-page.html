Agents page & the Connect funnel

The page allocates space in inverse proportion to how often you use it. Connecting an agent happens once; approving what one wants to do happens all day. Today connecting owns the screen and approving is below the fold.

This mock inverts that, and moves connection into a single button and a two-step modal.

What is wrong now

Observed on a real install, not hypothetical.

space
Four client cards carry 24 file paths permanently on screen — configuration detail that matters once and never again.
order
The emergency stop sits at the top with the same weight as primary content, and pending approvals — the only thing that blocks work — are last.
empty state
A fresh install renders five empty cards. Nothing to read, nothing to do, no obvious first move.
wrong promise
Every client offers Install even when the agent is not on the machine — and the button returns 502 ENOENT mkdir '/.claude/skills', because the local API resolves the project root to /.
wrong place
Wiring is a filesystem operation on the agent's own config. It belongs in a terminal you can see, not behind a dashboard button that writes to hidden paths.

The page, once something is connected

A status strip carries the whole connection story in one line — who is wired, what is live, the stop control. Everything below is ordered by whether it needs you.

Connect your agent — the funnel

Two steps. Pick the agent, then run one command. vops does not write into the agent's config from the dashboard: it shows you the command, and you can see exactly what it touches before it touches it.

Why these calls

no install button
Wiring edits files under ~/.claude, ~/.codex and friends. A command you run yourself is auditable and portable to a machine with no dashboard open; a dashboard button that silently rewrites agent config is neither.
paths on demand
The three files each install touches are still shown — inside the modal, for the one agent you picked. That is 3 paths at the moment you care, not 24 forever.
strip, not cards
Connection state is a fact, not a task. Four logos and a count answer "is this wired?" without spending a card on it.
approvals lead
It is the only thing on this page that blocks a person. When the queue is empty it collapses to one quiet line, so the page is short when nothing needs you.
